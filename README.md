# Banking Customer & Transaction Analysis using SQL

## 📌 Project Overview

This project analyzes over 1 million banking transactions using SQL to understand customer behavior, transaction patterns, spending levels, and business activity.

The project focuses on data cleaning, transformation, customer segmentation, transaction analysis, and extracting business insights using MySQL.

---

## 🎯 Business Objective

The main objectives of this project are to:

- Understand overall transaction performance
- Analyze monthly transaction activity
- Identify one-time and repeat customers
- Analyze customer spending behavior
- Segment customers based on total spending
- Identify high-value transactions and customers
- Analyze transaction activity by location, gender, and time of day
- Extract actionable business insights from transaction data

---

## 📊 Dataset

**Dataset:** Bank Customer Segmentation / Transaction Dataset

**Source:** Kaggle

### Dataset Size

- Transactions: **1,048,567**
- Unique Customers: **884,265**
- Date Range: **August 1, 2016 – October 21, 2016**
- Total Transaction Value: **₹165.08 crore**
- Average Transaction Amount: **₹1,574**

### Main Columns

| Column | Description |
|---|---|
| TransactionID | Unique transaction identifier |
| CustomerID | Customer identifier |
| CustomerDOB | Customer date of birth |
| CustGender | Customer gender |
| CustLocation | Customer location |
| CustAccountBalance | Account balance |
| TransactionDate | Transaction date |
| TransactionTime | Transaction time |
| TransactionAmount (INR) | Transaction amount in INR |
